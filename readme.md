# Real Estate Easy

## Overview
Real Estate Easy is a web application aimed at streamlining property management and real estate transactions. It allows users to browse, list, and manage properties with ease.

## Features
- Property listing and search functionality.
- User authentication and profile management.
- CRUD operations for property management.
- Interactive property maps.
- Advanced filtering options for property searches.

## Technologies Used
- **Frontend**: Makaan Template (HTML/CSS/JS)
- **Backend**: Symfony Framework
- **Database**: MySQL
- **Other Tools**: REST APIs

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/Aymankhallaf/real-estate-easy.git
    ```
2. Navigate to the project directory:
    ```bash
    cd real-estate-easy
    ```
3. Install backend dependencies:
    ```bash
    composer install
    ```
4. Set up the database:
    ```bash
    php bin/console doctrine:database:create
    php bin/console doctrine:migrations:migrate
    ```
5. Start the development server:
    ```bash
    symfony server:start
    ```
